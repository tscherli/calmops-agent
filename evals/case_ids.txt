# Every case id this suite has ever used. One id per line; a line starting
# with "retired " names an id that was used once and must never be reused.
#
# Why a file rather than a memory: a run-to-run comparison is keyed on the case
# id. Repurposing one -- new turns, same id -- silently changes what the
# comparison compares, and the numbers still line up neatly. Registering an id
# here is the deliberate act that makes that visible in a diff. The eval
# reports that would otherwise hold this record are gitignored
# (.gitignore: evals/results/*.md), so they cannot serve as the history.
#
# tests/test_evals_dataset.py enforces it: a case whose id is not registered
# fails, and so does a case reusing a retired one.
